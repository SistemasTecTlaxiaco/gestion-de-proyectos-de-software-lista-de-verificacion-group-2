## 🎯 Objetivo del Proyecto
Desarrollar y auditar un sistema de software robusto enfocado en apoyar a los artesanos locales de Tlaxiaco en la comercialización, control de inventario y cálculo de costos de producción de piezas de alfarería (ollas de barro) y cestería (canastas tejidas), aplicando rigurosamente los estándares de calidad de **CMMI** y **MoProSoft**, así como la metodología **eduScrum**.

---

## 📂 Estructura de Auditoría de Calidad
Este repositorio contiene la infraestructura de control de calidad, listas de verificación y el sistema de insignias automatizado:
- [`AUDITORIA-CMMI-MOPROSOFT.md`](AUDITORIA-CMMI-MOPROSOFT.md) - Mapeo de procesos de ingeniería de software al contexto artesanal.
- [`CHECKLIST-AUDITORIA.md`](CHECKLIST-AUDITORIA.md) - Criterios técnicos de evaluación en GitHub.
- [`SISTEMA-INSIGNIAS.md`](SISTEMA-INSIGNIAS.md) - Escala de madurez (Bronce, Plata, Oro).
- [`METRICAS-CALIDAD.md`](METRICAS-CALIDAD.md) - Indicadores de desempeño y costos de calidad.
- [`EVIDENCIAS-AUDITORIA.md`](EVIDENCIAS-AUDITORIA.md) - Matriz de pruebas y verificación de código.
- [`HALLAZGOS-AUDITORIA.md`](HALLAZGOS-AUDITORIA.md) - Reporte de no conformidades y acciones correctivas.

---

## 🏆 Sistema de Insignias Definido
* 🥇 **Oro (95% - 100%):** Automatización completa, control estricto de versiones y documentación impecable adaptada al dominio de las artesanías.
* 🥈 **Plata (85% - 94%):** Estructura completa con mínimas desviaciones en métricas.
* 🥉 **Bronce (70% - 84%):** Cumplimiento básico de requerimientos de control de cambios.
